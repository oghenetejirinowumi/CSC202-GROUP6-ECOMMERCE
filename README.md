# CSC202-GROUP6-ECOMMERCE
CSC 202 Group 6: Mini E-Commerce App A full-stack React 19 and Node.js application built with TypeScript, Prisma, and Supabase. Features a type-safe API, shadcn/ui components, and a automated Git workflow.

# Description
Teckvora is a web-based e-commerce platform that enables both customers and business owners to interact on a single platform and also allows users to browse, select, and purchase products across different categories such as electronics, food, and fashion, etc. It is designed to simulate a real world online marketplace by ensuring key functionality while also ensuring it is simple and user friendly.

# Project Objectives
- To design a simple functional e-commerce system.
- To provide a user-friendly interface for customers.
- To understand how online shopping platforms are operated.
- To practice teamwork and collaboration.
- To practice collaboration using Github.
- To create a proper and structured documentation of the entire process.

# Target Users 
- Students
- Small business owners
- Online shoppers
- Companies

# Features 

- Browse 87 gadget products across 5 top-level categories and 14 subcategories
- Filters products by brand, subcategory, and text search
- Sorts products A → Z or Z → A
- View a full product detail page with specs, rating, and price
- Add products to cart, adjust quantities, and remove items
- Persistent cart backed by the server (SQLite)
- User registration and login (backend fully functional; frontend wiring pending)
- Responsive layout built with Tailwind CSS

# Known Limitations

- Cart uses a hardcoded user_id = 1 (full auth integration is in progress)
- Login and signup forms are not yet connected to the backend API
- The search bar in the navbar is UI-only; per-page search is functional
- No checkout flow yet
- No session tokens or cookies — auth state is not persisted across page refreshes

Project is currently under development.
